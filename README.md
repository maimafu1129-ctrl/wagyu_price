# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
リモートリポジトリ　インターネット上で複数で作業するリポジトリ。
ローカルリポジトリ　パソコン上で個々で作業するリポジトリ。



## プッシュとマージの違いは何でしょうか？
push ローカル作業で作業内容を、サーバー上のリモートリポジトリにアップロードする事
marge　変更履歴をブランチに取り込むこと



## コミットとプッシュの違い
commit ファイルの追加、変更を保存すること
push　ローカルリポジトリからリモートリポジトリにアップすること


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
commit -m ' 変更内容'



## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
ローカルではここの作業で変更履歴を取り込むことで、プルリクエストはチームに向けて依頼すること


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
先にmargeした内容を取り込み、その後に次のmargeを取り込む、どちらの変更内容も取り込む。
